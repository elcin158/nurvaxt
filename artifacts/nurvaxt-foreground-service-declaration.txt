NurVaxt — Foreground Service declaration draft

Permission/type
FOREGROUND_SERVICE_SPECIAL_USE / specialUse

Feature description
NurVaxt provides an optional, user-visible countdown to the next verified prayer-time event. When notifications and the ongoing countdown setting are enabled, an Android foreground service maintains a silent ongoing notification showing the next event and remaining time while the app is in the background. The user can stop the feature from the app settings or Android's foreground-service controls. Prayer-time data is bundled offline; this service does not request location, record audio, or transmit data.

Impact if delayed or interrupted
Delaying the service would delay the user-requested ongoing countdown. Interrupting it would stop countdown updates or remove the persistent countdown notification, so the user could no longer rely on the displayed remaining time while outside the app. Scheduled prayer reminders are handled separately; this declaration concerns the ongoing countdown display.

Duration and stop controls
The service runs while the user has enabled notifications and the ongoing countdown and a verified upcoming event is available. It stops and removes its notification when the countdown is disabled, notifications are disabled or unavailable, or no verified event is available. Android force-stop and system foreground-service controls can also stop it. It performs local time calculations without a wake lock; updates are aligned to minutes, with final-minute seconds only while the screen is interactive.
